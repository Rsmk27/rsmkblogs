An architectural guide to constructing privacy-first, cloud-independent smart home networks using local control hubs and low-power wireless mesh protocols.

---

## 1. Local Control vs Cloud Architecture

Relying on external cloud APIs introduces latency and privacy risks. **Home Assistant** running on dedicated SBC hardware manages local Zigbee, Z-Wave, and Matter devices without requiring internet connectivity.

---

## 2. Zigbee 3.0 Mesh Topology

Zigbee routers (mains-powered smart plugs/switches) automatically relay packets across the mesh, extending RF coverage throughout large structures for low-power battery-operated end devices.
