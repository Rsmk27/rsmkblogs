## 1. Microcontroller Architecture Specifications

The **Arduino Nano** is driven by Microchip's ATmega328P 8-bit AVR RISC-based microcontroller. Running at 16 MHz with 32 KB flash memory, 2 KB SRAM, and 1 KB EEPROM, it remains the standard teaching board for register-level hardware programming.

---

## 2. Register Bit Manipulation (Direct Port I/O)

While high-level functions like `digitalWrite()` are beginner-friendly, writing directly to Port registers (`DDRB`, `PORTB`, `PINB`) executes in a single clock cycle (62.5 nanoseconds at 16 MHz).

```c
#include <avr/io.h>
#include <util/delay.h>

int main(void) {
    // Set PB5 (Digital Pin 13) as Output
    DDRB |= (1 << DDB5);

    while(1) {
        // Toggle PB5 high/low using register XOR
        PORTB ^= (1 << PORTB5);
        _delay_ms(500);
    }
}
```

## 3. Hardware Timers & PWM Generation

The ATmega328P includes two 8-bit timers (Timer0, Timer2) and one 16-bit timer (Timer1). Hardware **PWM** generation allows non-blocking speed control of DC motors and LED brightness modulation without CPU overhead.

## Key Takeaways

- **Direct Port I/O:** Bypassing `digitalWrite()` using `PORTB` register bitwise operations improves execution speed by up to 40x.
- **Hardware Timers:** Timer1 provides 16-bit precision for high-resolution PWM motor control.
- **Memory Footprint:** Efficient C code structure allows complex state machines to fit within 2 KB SRAM bounds.
